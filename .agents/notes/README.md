# .agents/notes/ — 文档层

决策与依据记录的目录说明。
写记录的规则见 [AGENTS.md](AGENTS.md)。

## 两类记录

| 类型 | 触发源 | 装什么 | 命名 |
| --- | --- | --- | --- |
| 决策类 | 做选择（几个方案里挑一个） | 问题、决策、替代方案、影响 | `YYYY-MM-DD-<主题>.md` |
| 依据类 | 做调查（看事实、对照、下结论） | 背景、结论、支撑的决策、影响 | `<主题>.md` |

判据：触发源是「做选择」还是「做调查」。
调查结论喂给某个决策时，依据类用 `## 支撑的决策` 指回决策类，不复制决策内容。

## 去哪查

本目录不建索引文件，也不逐篇列清单。
需要找某条决策时按主题名检索文件名，状态行标明它是否仍然生效。

## 与事故复盘的分界

- 事故触发 → `docs/postmortem/`。
- 决策触发 / 调查触发 → 本目录。
