# .agents/notes/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

## 本目录特有约束

- 每篇笔记第 3 行必须是状态行，四值之一：`状态：生效` / `状态：被取代` / `状态：已否决` / `状态：已归档`。
- `被取代` 必须跟一行指针；`已归档` / `已否决` 必须跟一句话理由。
- 归档形态是**就地标记**，不建 `archived/` 子目录。
- 决策类必须有 `## 替代方案（强制）`，写清试过什么、为什么不行。
- 依据类不强制替代方案，但若有下游决策必须写 `## 支撑的决策` 指针。
- 已实施的决策用现在时描述 shipped 事实；决策反转时写新记录并交叉引用，不改旧记录的结论。
- 不建索引文件，不逐篇列清单。

## 边界

- 记录怎么组织、命名约定 → [README.md](README.md)。
- 设计决策正文 → [../../docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md)。
- 事故复盘不放这里，放 `docs/postmortem/`。
